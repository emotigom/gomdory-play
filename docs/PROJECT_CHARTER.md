# 프로젝트 헌장

## 목적

gomdory-play는 아이들이 3D 세계에서 움직이고, 자신의 코드를 실행하며 결과를 바로 이해하도록 돕는 제품입니다. 첫 작품은 **골목 199X — 비석치기**입니다.

## 경계

`gom-clean`은 www.gomdory.com의 검색 페이지, 교사 화면, 로그인, 과제, 장기 진도를 맡습니다. `gomdory-play`는 실제 3D 플레이와 코딩 실행을 맡습니다. 두 제품은 역할을 명확히 나누며 코드를 복사하지 않습니다.

## 이번 단계

이번 단계는 개발 기반과 계약만 세웁니다. 플레이 가능한 게임이나 계정 기능을 약속하지 않습니다.
